# 写手派活模板(主编填的是「这次任务的值」,不是「怎么写」)

> **这张任务卡 = 这次任务的参数(数据)**:哪条选题、哪个账号、什么模式、料和产物在哪。**它不含"怎么写"**——你是谁、怎么干活、每拍怎么做,全在 `写手.md`(系统提示词)+ 各拍 skill(skill 自己声明要读哪些库/产物)。换领域/账号只换这些值,模板本身不动。
> 派给「写手」子 agent 当 prompt。逐拍靠 `beats/` 产物接力:写手每拍把产物 Write 到 beats/、停下;主编过审/回填选定后再派下一拍(本 harness 无 SendMessage,不靠同一写手的多轮记忆)。
