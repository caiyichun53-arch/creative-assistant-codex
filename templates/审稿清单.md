# 审稿清单(篇级闸 · 可数 · PASS/WARN/FAIL)

> **这是什么**:成稿后的**第一道闸**,只测**整篇层面**的硬伤。机械逐条判,不是"觉得像不像 AI"。
> **谁来跑**:我(信使)或检测子 agent。**绝不让用户跑**——用户只做终审品味。
> **门是串行的**:`审稿(篇级·本清单)先 → 写手照打回意见改 → humanizer-zh(句级)后`。结构崩的稿不先润色,省一轮。
> **和 humanizer 划死界**:句级 AI 味(破折号/此外/三段式/否定排比/系动词回避…那 24 个模式 + 5维评分)**全归 humanizer-zh,本清单一律不碰**,避免两个检测器对同一句给矛盾意见。本清单只看整篇层面的事。
> **合同优先**:审稿前必须读取 `data/topics/<topic_id>/creation_contract.md`。本清单只提供通用底线;本次选题的核心打法、经验动作和 FAIL 条款以总编辑合同为准。
> **判据来源**:`写手.md` 铁律 + `真人写作基石` + 记忆 `writing-system-architecture-gate`(文章编辑部的"可数+检验方法+PASS/FAIL+引原文"用法)。

## 怎么用
先判合同,再判通用清单。逐条判 **PASS / WARN / FAIL**。
- **合同条款没执行 = FAIL**。例如合同要求“第一句只抛反常识,不解释原因”,成稿第一句直接解释原因,即使文字顺也 FAIL。
- **经验只写在【思考】里,正文句子没体现 = FAIL**。总编辑合同的“经验转译动作”必须能在正文里找到对应句子。
- **FAIL 必须引原文那一句 + 一句话说清问题**(交不出证据 = 不算 FAIL 也不算 PASS,得说清)。
- **任一 ⭐关键项 FAIL = 整篇 FAIL**,打回写手改;改完重判。
- 全部 ⭐过、WARN 可接受 → 篇级通过,进 humanizer 句级。

## 0. 总编辑合同验收(先判)
读取 `creation_contract.md`,逐条检查:
1. ⭐ **钩子合同兑现** —— 检验:第一句是否按合同制造悬念/反常识,且没提前解释核心答案。
2. ⭐ **结构合同兑现** —— 检验:大纲或成稿主干是否按合同主打法推进,没有临场换套路。
3. ⭐ **经验动作落入正文** —— 检验:合同里的至少 1 个经验转译动作能在正文具体句子中找到。
4. ⭐ **审稿 FAIL 条款未命中** —— 检验:合同“审稿验收条款”中的 FAIL 条款是否命中。

任一合同 ⭐ FAIL,整篇 FAIL。先按合同打回,不要进入泛泛润色。

## A. 钩子 / 开头
1. ⭐ **第一句不剧透结论** —— 检验:读第一句。它若已把视频的核心答案/结论说破 = FAIL。
2. ⭐ **最冲击那句放第一句,无铺垫** —— 检验:第一句是否含冲突/悬念/反常识;若前面垫了"今天我们来聊聊…/大家有没有发现…"式开场 = FAIL。
3. **钩子靠台词立,不靠画面** —— 检验:开头有没有写"画面/镜头/出现…"等非台词内容 = FAIL。

## B. 结构
4. ⭐ **结构兑现选定打法** —— 检验:对照写手【思考】里点名选定的结构打法,主干节拍是否照做;跑去用了别的套路 = FAIL。
5. **说完就停,没有 AI 尾巴** —— 检验:结尾是否在信息给完后收住;出现"总结升华 / 展望未来 / 号召点赞关注" = FAIL。
6. **不复述对标原文** —— 检验:与 brief 里对标口播原文比对,有整段照搬或同序复述 = FAIL。

## C. 增量(二创内核)
7. ⭐ **有竞品没讲的信息增量** —— 检验:稿里能点出至少 2 处来自研究包、对标爆款没讲的事实点;0 处 = FAIL。
8. **每段都在推进** —— 检验:逐段看有没有"水段"(只重复上段、无新信息)。水段 1 段 = WARN,≥2 段 = FAIL。

## D. 真人节奏(篇级口径;单句问题留给 humanizer)
9. **设问后自答的节奏在场** —— 检验:全篇有没有用"设问→自答"往前推(真人写作基石跨作者第一铁律)。通篇平铺、一处设问都没有 = WARN。
10. **整篇句长有起伏** —— 检验(机械):是否出现连续 ≥3 句字数相近(相邻句长差都 <5 字)。出现 = WARN(只看整篇节奏曲线;具体哪句太平由 humanizer 管)。
11. **第一人称、口语在场** —— 检验:全篇有没有"我/你/咱"等口语人称和口语词。通篇书面、零口语 = FAIL。

## E. 口播体裁
12. ⭐ **只有"说出来的话"** —— 检验:全篇有没有混进分镜/画面/字幕/BGM/转场指示(口播标注 `/` 和语气括号如"(加重)"不算) = FAIL。
13. **篇幅达标** —— 检验:字数落在工单目标篇幅的 ±20%(或领域配置区间)内;超出 = WARN。

## 输出格式(给我/检测子 agent 填)
```
审稿结果:PASS / FAIL(任一⭐ FAIL 即整篇 FAIL)
逐条:
A1 ⭐ PASS
A2 ⭐ FAIL —— 原文"今天咱们聊聊不锈钢" / 第一句在铺垫没冲击
...
打回意见(给写手):
- 第一句重写:把"…"那句最冲击的提到开头,删掉铺垫(A2)
- 补增量:研究包里"X"这点竞品没讲,加进第2拍(C7)
```
> 篇级过了再交 humanizer-zh 跑句级。改稿回流走 `diff_draft.py`(阶段5)。
