# 钩子拍

这一拍只产候选开头，不写大纲或正文。

## 权威手册

读取 `.claude\skills\钩子\SKILL.md`。

## 输入

- 任务卡
- `brief.md`
- `beats/对齐.md`

## 步骤

1. 读取钩子手册、brief 和对齐产物。
2. 生成 3 个不同角度/不同策略的候选开头。
3. 标注每个钩子的角度和策略。
4. 推荐一个，但不替用户终选。
5. 写入 `beats/钩子.md` 后停下。

## 输出

- `beats/钩子.md`

## 验收

- 正好有 3 个候选。
- 角度不重复。
- 每个都是能说出口的口播开头。
- 没有正文、大纲、分镜。

## 禁止

- 不剧透核心结论。
- 不为冲击编数字或放大事实。
- 不把最猛的料一次倒光。
