# 优化诊断

这一步在篇级审稿通过后，把合格稿再提一档。只产意见，不改稿。

## 权威手册

读取 `.claude\skills\优化诊断\SKILL.md`，必要时读取 `精修` 手册里的优化维度。

## 输入

- 已通过篇级审稿的 `draft_v1.md`
- `beats/审稿.md`

## 步骤

1. 通读 draft。
2. 按优化维度找能更好的段落。
3. 每条意见都引用原文并给一句具体改法。
4. 写入 `beats/优化意见.md`。

## 输出

- `beats/优化意见.md`

## 验收

- 意见具体到句或段。
- 没有重复审稿硬伤。
- 可以判定“无需优化”，但必须说明。

## 禁止

- 不直接改正文。
- 不处理句级 AI 味。
- 不为优化而硬挑。
