# 大纲拍

这一拍只搭结构骨架，不写全文。

## 权威手册

读取 `.claude\skills\大纲\SKILL.md`。

## 输入

- 任务卡
- `brief.md`
- `beats/对齐.md`
- `beats/钩子.md` 中标记【选定】的开头

## 步骤

1. 确认已有【选定】钩子。
2. 读取结构打法路由表和大纲手册。
3. 选择一套结构并说明理由。
4. 排 3-5 拍，每拍一句话。
5. 写入 `beats/大纲.md` 后停下。

## 输出

- `beats/大纲.md`

## 验收

- 有选定结构。
- 有 3-5 拍骨架。
- 每拍能接住上一拍并推进信息。
- 没有正文台词。

## 禁止

- 不跳过钩子终选。
- 不照搬来源顺序。
- 不写分镜或画面。
