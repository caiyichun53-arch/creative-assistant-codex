# 对标账号注册

## 使用时机

当用户已经有明确的对标账号,并要求把它加入创作助手的对标账号池时使用。

典型说法:

- “把这个对标账号注册进去。”
- “新增一个对标账号。”
- “这是某某账号主页链接,加入泛科普领域。”
- “先登记这个竞品账号,后面再采集。”

不适用:

- 用户要新建自营领域账号。
- 用户只是在讨论应该找哪些对标账号。
- 用户要求采集账号视频。
- 用户要求判定爆款。
- 用户要求拆解某条爆款。

## 目标

把一个对标账号登记到本地账号池,形成可被后续采集脚本读取的 `competitor_accounts` 记录,并输出注册验收结果。

## 输入

必须输入:

- 对标账号名称、主页链接、短链或 `sec_uid`:用于解析抖音账号身份并生成标准主页链接。
- 领域名称:用于写入账号归属,例如“泛科普”。如果用户未提供,先询问;不要默认塞进旧领域。


不接受的输入:

- 自营账号名称:自营账号由“新建领域账号”技能处理。
- 视频链接:本技能只登记账号,不登记视频。
- 采集数量、观察天数、爆款阈值:这些属于采集和爆款判定流程。
- 禁用词、风险边界、人设材料:这些不属于对标账号注册。

缺少必须输入时先停止,列出缺项,不要自行编造。

## 依赖

执行本技能必须具备:

- 对标账号注册脚本: `scripts/collect/register_competitor.py`,或当前项目等价的注册脚本。
- 账号身份解析能力: `scripts/collect/common.py` 中的解析函数,或当前项目等价实现。
- 本地状态数据库: `data/creation.db`,或当前项目等价的数据库。
- 对标账号表: `competitor_accounts`,或当前项目等价的对标账号记录表。

如果当前项目没有这些等价依赖,停止并说明缺少哪一类执行能力。

## 可读取参考

禁止读取:

- 全量 `vault/范例/`。
- 全量 `vault/语感燃料/`。
- 爆款拆解笔记全文。

## 执行步骤

1. 检查输入。
   - 如果缺少账号链接、短链或 `sec_uid`,停止并要求用户提供。
   - 如果缺少领域名称,停止并要求用户提供领域名称。
   - 如果输入是视频链接而不是账号链接,停止并说明本技能只注册账号。

2. 检查领域。
   - 如果 `config/domains/<领域名称>.yaml` 存在,继续第 3 步。
   - 如果领域配置不存在,停止并询问用户是先新建领域账号,还是仍然把该对标账号登记到这个新领域名下。
   - 未得到明确确认前,不要把账号写进不存在的领域。

3. 预览现有账号池。
   - 运行:

   ```powershell
   python scripts/collect/register_competitor.py --list
   ```

   - 如果账号池已经有同名账号,但无法确认是否同一个主页,继续第 4 步,以 `sec_uid` 去重为准。
   - 如果用户明确表示这是重复账号,停止,不要重复注册。

4. 调用确定性脚本登记账号。
   - 有账号名称时运行:

   ```powershell
   python scripts/collect/register_competitor.py <账号主页链接或短链或sec_uid> --name <对标账号名称> --domain <领域名称>
   ```

   - 没有账号名称时运行:

   ```powershell
   python scripts/collect/register_competitor.py <账号主页链接或短链或sec_uid> --domain <领域名称>
   ```

5. 验收账号记录。
   - 再次运行账号池列表,确认新增或更新后的账号存在。
   - 检查注册输出里有账号 `id`、账号名称和 `sec_uid`。
   - 如果脚本提示无法解析 `sec_uid`,停止并要求用户提供有效主页链接或短链。

6. 输出注册报告。
   - 明确列出账号名称、领域、账号池编号、标准主页链接或 `sec_uid`。
   - 明确说明本次只完成注册,没有采集视频,没有判定爆款。
   - 如果用户下一步要采集,提示应进入采集流程,不要在本技能里直接执行。

## 输出

必须产出:

- 数据库记录: `competitor_accounts` 表中新增或更新一条对标账号记录。
- 注册报告:包含账号池编号、账号名称、领域、平台、`sec_uid` 或标准主页链接。

不产出:

- 视频记录。
- 观察池记录。
- 爆款库记录。
- 爆款拆解笔记。
- 经验范例。

## 合格检查

关键项:

- 输入账号链接、短链或 `sec_uid` 可解析: 通过 / 失败。
- 领域已存在或用户确认写入该领域名: 通过 / 失败。
- `competitor_accounts` 表有该账号记录: 通过 / 失败。
- 账号记录的领域等于输入领域: 通过 / 失败。
- 没有启动采集: 通过 / 失败。
- 没有判定爆款: 通过 / 失败。
- 没有写入经验或范例: 通过 / 失败。

警告项:

- 未提供对标账号名称: 警告,但不阻断;脚本会使用临时名称。

任一关键项失败,不得进入采集或爆款判定流程。

## 禁止事项

- 禁止新建自营领域账号。
- 禁止采集视频。
- 禁止把注册存量视频塞进观察池。
- 禁止判定爆款。
- 禁止拆解爆款。
- 禁止生成选题。
- 禁止写稿或审稿。
- 禁止写入经验、范例或方法论。
- 禁止为了注册账号读取整个经验库。

## 失败处理

- 缺少账号链接、短链或 `sec_uid`:停止并要求补充。
- 缺少领域名称:停止并要求补充。
- 领域不存在且用户未确认:停止,不要写库。
- 脚本无法解析账号身份:停止并要求提供有效链接。
- 数据库不存在:停止并提示先初始化数据库。
- 脚本失败:停止并报告错误,不要手工直接改数据库。
- 权限不足:停止并说明需要访问数据库和脚本路径。

## 是否回写经验

不回写经验。

本技能只登记账号池记录。对标账号后续产生的视频、爆款、拆解和经验晋升,由后续技能或脚本处理。

## 多领域适配

领域名称来自用户输入或领域配置,写入 `competitor_accounts.domain`。同一套注册脚本服务所有领域,不得因为新增领域复制一套注册代码。

当前平台默认是抖音。以后新增平台时,必须先扩展确定性脚本和数据库字段使用方式,不能让模型凭经验临时解析。
