# 新建领域账号

## 使用时机

当用户要新增一个内容领域、一个自营账号,或把创作助手扩展到新账号时使用。

典型说法:

- “新建一个音乐领域账号。”
- “我要做一个新账号,先把领域和人设建起来。”
- “把这个系统扩展到情感领域。”
- “给某个新账号初始化配置。”

不适用:

- 用户只是要注册对标账号。
- 用户只是要采集视频。
- 用户已经选中选题并要求创作。
- 用户要求审稿、润色或经验提炼。
- 用户只是要配置禁用词或内容风险边界。

## 目标

创建一个可被创作助手识别的新领域账号,完成基础配置、人设、经验库目录和数据库账号登记。完成后,系统应该能在后续步骤里按领域和账号读取配置,而不是继续写死旧账号。

## 输入

必须输入:

- 领域名称:用于生成 `config/domains/<领域名称>.yaml`,并作为后续经验库和选题归属。
- 账号名称:用于生成 `config/accounts/<账号名称>.yaml`、人设文件和数据库账号记录。
- 平台:当前默认只支持抖音。
- 账号主页链接:如果账号已经开通,用于写入账号配置;如果账号尚未开通,填写“待开通”。本技能不解析额外的平台账号标识。
- 内容方向:用于领域配置和人设文件。
- 目标受众:用于领域配置和人设文件。
- 字数范围:用于写作验收口径,例如 1300-1700 字。脚本会自动取区间中点写入配置,只是为了兼容现有材料包和创作脚本。
- 人设材料:用于生成 `vault/人设/<账号名称>.md`。

不接受的输入:

- 对标账号链接。对标账号属于后续“规划对标账号/注册对标账号”技能,本技能不接收,也不暂存。
- 禁用词或风险边界。禁用词和风险边界属于后续硬规则配置或校验器,本技能不接收。
- 平台账号标识。只保留账号主页链接。

缺少必须输入时先停止,列出缺项,不要自行编造。

## 依赖

执行本技能必须具备:

- 领域配置目录: `config/domains/`,或当前项目等价的领域配置位置。
- 账号配置目录: `config/accounts/`,或当前项目等价的账号配置位置。
- 人设或知识库目录: `vault/`,或当前项目等价的经验库位置。
- 确定性初始化脚本: `scripts/setup/create_domain_account.py`,或当前项目等价的初始化脚本。
- 本地状态数据库: `data/creation.db`,或当前项目等价的数据库。
- 账号表: `accounts`,或当前项目等价的账号记录表。

如果当前项目没有这些等价依赖,停止并说明缺少哪一类执行能力。不要因为缺少 `AGENTS.md`、`BUILD_PLAN.md`、`CLAUDE.md` 这类项目说明文件而阻断执行。

## 可读取参考

通常不需要读取参考材料。这个技能的落地动作由初始化脚本完成,代理不需要先阅读人设、账号配置样例或目录结构来“学习格式”。

仅在以下情况按需读取:

- 脚本参数和技能正文不一致时,查看初始化脚本的帮助信息或脚本开头说明。
- 验收数据库记录失败时,查看数据库结构或用数据库自省确认账号表字段。
- 当前项目没有等价初始化脚本,需要人工迁移技能时,再读取少量现有配置样例理解格式。
- 项目存在特殊边界且用户要求遵守时,读取 `AGENTS.md`、`BUILD_PLAN.md`、`CLAUDE.md` 或同类说明;不存在不阻断。

不要为了执行本技能而读取现有人设正文、全量账号配置、全量领域配置或目录结构。

禁止读取:

- 全量 `vault/范例/`。
- 全量 `vault/语感燃料/`。
- 旧项目代码。
- 无关领域的大量经验材料。

## 执行步骤

1. 判断领域归属。
   - 如果领域配置已存在,这是“已有领域新增账号”。继续第 2 步,但不得覆盖领域配置。
   - 如果领域配置不存在,这是“新建领域和账号”。继续第 2 步,并允许脚本创建领域配置。
   - 如果无法判断用户说的是新领域还是旧领域的新账号,停止并只问这个问题。

2. 检查账号是否已存在。
   - 如果账号配置不存在,继续第 3 步。
   - 如果账号配置已存在,停止并询问用户是复用现有账号、覆盖配置,还是换账号名。
   - 未得到明确覆盖确认前,不得传入覆盖参数。

3. 检查输入完整性。
   - 账号主页链接如果是“待开通”,继续执行,但在最终报告里标为警告。
   - 字数范围只检查上下限,不要求模型精确写到某个数字。
   - 如果字数下限大于上限,停止并要求用户修正。

4. 调用确定性脚本。

   ```powershell
   python scripts/setup/create_domain_account.py --domain <领域名称> --account <账号名称> --platform douyin --profile-url <账号主页链接或待开通> --description <内容方向> --audience <目标受众> --range-min <字数下限> --range-max <字数上限> --persona-text <人设材料>
   ```

   说明:脚本会自动把字数范围中点写入 `script_target_chars`,这是兼容字段,不是要求正文精确到这个字数。

5. 验收脚本产物。
   - 逐项检查领域配置、账号配置、人设文件、经验库目录和数据库账号记录。
   - 如果任何关键项失败,停止并报告失败项。

6. 输出初始化报告。
   - 明确说明本次只完成领域账号初始化。
   - 明确说明未注册对标账号、未采集视频、未写入经验。
   - 如果用户提供了对标账号链接或禁用词,提示应交给后续对应技能处理,不要在本技能内处理。

## 输出

必须产出:

- 领域配置: `config/domains/<领域名称>.yaml`
- 账号配置: `config/accounts/<账号名称>.yaml`
- 人设文件: `vault/人设/<账号名称>.md`
- 经验库基础目录:
  - `vault/范例/选题/`
  - `vault/范例/钩子/`
  - `vault/范例/结构/`
  - `vault/范例/文风/`
  - `vault/语感燃料/<领域名称>/`
- 数据库账号记录: `accounts` 表新增或确认一条记录。
- 初始化报告: 列出每一项通过、警告或失败。

## 合格检查

关键项:

- 领域配置存在或已确认复用: 通过 / 失败。
- 账号配置存在: 通过 / 失败。
- 人设文件存在: 通过 / 失败。
- 数据库 `accounts` 表有该账号: 通过 / 失败。
- 账号记录的领域等于输入领域: 通过 / 失败。
- 经验库基础目录存在: 通过 / 失败。
- 没有注册对标账号: 通过 / 失败。
- 没有启动采集: 通过 / 失败。
- 没有写稿: 通过 / 失败。
- 没有写入经验或晋升范例: 通过 / 失败。

任一关键项失败,不得进入“规划对标账号”或后续采集流程。

警告项:

- 账号主页链接为“待开通”: 警告,但不阻断。
- 新领域没有对标账号: 不在本技能内警告。对标账号由后续技能处理。

## 禁止事项

- 禁止接收或暂存对标账号链接。
- 禁止注册对标账号。
- 禁止采集视频。
- 禁止判定爆款。
- 禁止生成选题。
- 禁止写稿。
- 禁止审稿。
- 禁止配置禁用词或风险边界。
- 禁止把旧领域的范例复制成新领域经验。
- 禁止把禁用词或风险边界塞进生成提示。
- 禁止把新领域写死进业务代码。

## 失败处理

- 缺少必须输入: 停止并列出缺项。
- 领域归属不清: 停止并询问是新领域还是已有领域新账号。
- 账号配置已存在: 停止并询问复用、覆盖或换名。
- 数据库不存在: 停止并提示先初始化数据库。
- 脚本失败: 停止并报告错误,不要手工补半套文件。
- 权限不足: 停止并说明需要写入哪些路径。

## 是否回写经验

不回写经验。

本技能只初始化新领域账号。它可以创建空经验库目录,但不能写入经验、晋升范例或生成方法论。

## 多领域适配

领域差异只写入配置、人设和经验库。新增领域不得新增一套领域专属流程代码。

后续技能必须从领域配置和账号配置读取:

- 领域名称。
- 账号名称。
- 平台。
- 人设路径。
- 字数范围。

不要继续写死“泛科普”或“张芝士”。
