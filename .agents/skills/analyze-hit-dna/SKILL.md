# 爆款拆解

## 使用时机

当用户要求拆解一条或一批已验证爆款,分析它的选题、开头钩子、结构、张力和可裂变选题方向时使用。

典型说法:

- “拆解这个爆款。”
- “把 hit 68 做 DNA 拆解。”
- “看看还有哪些爆款没拆。”
- “批量跑一下爆款拆解。”

不适用:

- 用户要注册对标账号。
- 用户要采集视频。
- 用户要判断一个视频是不是爆款。
- 用户要把多条拆解归纳成方法论或范例。
- 用户要基于某个选题写稿。

## 目标

对已备料的爆款视频生成一份可追溯的拆解笔记,并把笔记路径回写到 `hits.dna_note_path`,让后续材料包、共性归纳和创作流程可以引用。

## 输入

二选一:

- 爆款编号:对应 `hits.id`,用于单条拆解。
- 批量拆解指令:用于拆解所有“已有口播文案但还没有拆解笔记”的代表性爆款。

可选输入:

- 只看进度:用于查看当前还有多少爆款待拆。

不接受的输入:

- 对标账号主页链接:这是“对标账号注册”或采集流程的输入。
- 普通视频链接:普通视频必须先入库、判定为爆款并完成备料。
- 写作主题、人设、禁用词:这些不属于爆款拆解。

## 依赖

执行本技能必须具备:

- 爆款拆解脚本: `scripts/reverse/dna.py`,或当前项目等价的拆解脚本。
- 语言模型调用入口: `scripts/llm/call.py`,或当前项目等价实现。
- 本地状态数据库: `data/creation.db`,或当前项目等价的数据库。
- 爆款表: `hits`,或当前项目等价的爆款记录表。
- 对标账号表: `competitor_accounts`,或当前项目等价的账号归属表。
- 目标爆款的口播文案文件。

如果当前项目没有这些等价依赖,停止并说明缺少哪一类执行能力。不要因为缺少 `AGENTS.md`、`BUILD_PLAN.md`、`CLAUDE.md` 这类项目说明文件而阻断执行。

单条拆解前,目标爆款必须满足:

- `hits.id` 存在。
- `hits.transcript_path` 不为空。
- 口播文案文件存在。
- `hits.dna_note_path` 为空,或用户明确要求检查已有拆解结果。

## 可读取参考

通常不需要读取参考材料。拆解脚本会读取口播文案并生成拆解笔记,代理不需要先打开口播文案、人设、账号配置或经验库。

仅在以下情况按需读取:

- 脚本参数和技能正文不一致时,查看爆款拆解脚本的帮助信息或脚本开头说明。
- 验收回写失败时,查看数据库结构或用数据库自省确认爆款表字段。
- 批量拆解中断或撞额度时,查看 `logs/dna_batch.log` 排查完成数量和失败原因。
- 只需要确认口播文案文件是否存在时,检查路径存在性即可,不要读取全文。
- 项目存在特殊边界且用户要求遵守时,读取 `AGENTS.md`、`BUILD_PLAN.md`、`CLAUDE.md` 或同类说明;不存在不阻断。

不要为了拆解爆款而读取人设、账号配置、全量拆解笔记或经验库。

禁止读取:

- 全量 `vault/范例/`。
- 全量 `vault/方法论/`。
- 全量 `data/爆款拆解/`。
- 旧项目代码。

## 执行步骤

1. 判断任务类型。
   - 如果用户给出爆款编号,执行单条拆解。
   - 如果用户要求“批量拆解”或“继续拆解”,执行批量拆解。
   - 如果用户只是问进度,执行进度查看。
   - 如果无法判断是哪一种,停止并询问用户是单条、批量还是看进度。

2. 进度查看。
   - 运行:

   ```powershell
   python scripts/reverse/dna.py --status
   ```

   - 输出当前已拆和待拆数量。
   - 不生成新拆解笔记。

3. 单条拆解前检查。
   - 确认 `hits.id` 存在。
   - 如果该爆款不存在,停止并报告“爆款编号不存在”。
   - 如果 `transcript_path` 为空,停止并说明该爆款还没有完成备料,需要先跑备料层。
   - 如果 `dna_note_path` 已存在,停止并询问用户是查看已有笔记,还是明确重跑。当前脚本默认幂等跳过批量已拆,单条重跑可能覆盖笔记,不得默认执行。

4. 单条拆解。
   - 运行:

   ```powershell
   python scripts/reverse/dna.py --hit <爆款编号>
   ```

   - 如果脚本输出“撞会话上限”,停止,报告已安全中断和可重试时间。
   - 如果脚本成功,继续第 6 步验收。

5. 批量拆解。
   - 先运行:

   ```powershell
   python scripts/reverse/dna.py --status
   ```

   - 如果待拆数量为 0,停止并报告无需拆解。
   - 如果待拆数量大于 0,运行:

   ```powershell
   python scripts/reverse/dna.py --batch
   ```

   - 批量拆解可能消耗语言模型额度。运行前如果用户没有明确同意批量执行,先停下确认。
   - 如果撞额度或会话上限,停止并报告本轮已完成数量、剩余数量和下次续跑方式。

6. 验收拆解结果。
   - 确认 `data/爆款拆解/` 下生成对应拆解笔记。
   - 确认 `hits.dna_note_path` 已写入相对路径。
   - 确认 `hits.reverse_status` 为 `done`。
   - 如果任何一项失败,停止并报告失败项。

7. 输出拆解报告。
   - 单条拆解报告包含爆款编号、标题、拆解笔记路径、回写状态。
   - 批量拆解报告包含本轮拆解数量、剩余数量、日志路径。
   - 明确说明本次只做爆款拆解,没有归纳共性、没有晋升经验、没有写稿。

## 输出

单条拆解必须产出:

- 爆款拆解笔记: `data/爆款拆解/<标题>.md`
- 数据库回写: `hits.dna_note_path`
- 状态回写: `hits.reverse_status='done'`
- 拆解报告:爆款编号、标题、笔记路径、回写状态。

批量拆解必须产出:

- 多条爆款拆解笔记。
- 批量日志: `logs/dna_batch.log`
- 批量报告:已拆数量、剩余数量、是否撞额度。

不产出:

- 领域方法论。
- 选题范例。
- 开头钩子范例。
- 结构范例。
- 草稿。

## 合格检查

关键项:

- 目标爆款存在: 通过 / 失败。
- 口播文案路径存在: 通过 / 失败。
- 拆解笔记已生成: 通过 / 失败。
- `hits.dna_note_path` 已回写: 通过 / 失败。
- `hits.reverse_status` 为 `done`: 通过 / 失败。
- 没有注册对标账号: 通过 / 失败。
- 没有采集视频: 通过 / 失败。
- 没有判定爆款: 通过 / 失败。
- 没有晋升经验或范例: 通过 / 失败。

警告项:

- 撞语言模型额度或会话上限: 警告,已拆内容保留,后续可续跑。
- 批量待拆数量较多: 警告,需要用户确认是否消耗额度。

任一关键项失败,不得进入归纳共性或创作流程。

## 禁止事项

- 禁止注册对标账号。
- 禁止采集视频。
- 禁止判定爆款。
- 禁止把普通视频直接当爆款拆解。
- 禁止在没有口播文案的情况下编造拆解。
- 禁止一次把多条爆款合并成一篇拆解。
- 禁止把拆解结果直接晋升为范例或方法论。
- 禁止写稿、审稿或生成选题材料包。
- 禁止为了拆解读取整个经验库。

## 失败处理

- 爆款编号缺失:停止并要求提供 `hits.id`。
- 爆款不存在:停止并报告编号不存在。
- 口播文案缺失:停止并提示先执行爆款备料。
- 拆解笔记已存在:停止并询问查看还是明确重跑。
- 语言模型额度或会话上限:停止并报告脚本输出的重试时间。
- 脚本失败:停止并报告错误,不要手工补写 `dna_note_path`。
- 权限不足:停止并说明需要写入 `data/爆款拆解/`、`logs/` 和数据库。

## 是否回写经验

不回写经验。

本技能只写中间拆解笔记和数据库状态。拆解结果进入方法论、选题范例、开头钩子范例或结构范例,必须由后续“归纳共性/经验晋升”技能处理。

## 多领域适配

领域来自爆款所属对标账号的 `competitor_accounts.domain`。拆解逻辑通用于所有领域,拆解笔记记录领域信息,但不得因为新增领域复制一套拆解脚本。

不同领域可以在后续共性归纳和经验晋升阶段形成不同范例库;本技能只负责逐条拆解。
