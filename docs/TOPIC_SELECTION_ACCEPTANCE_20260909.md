## 修复了什么

- 原来来源转题只接受预冻结材料且禁止搜索，日常又经常只传标题。现在普通线索由当前 Agent 搜索和阅读，Core 同时传入已保存的完整正文。
- 原来音乐的宽泛领域描述覆盖了具体禁项。现在成题与评分读取同一份领域允许、排除和具体交付说明；专业乐评、听感、乐理、编曲和演唱技术分析明确排除。通用步骤没有写成音乐故事模板。
- 原来固定七种角度偏向机制解释，弱候选与待审核状态也能入池。现在自然找方向，只有成形候选或不转题两种结果，不额外设置候选资格环节，不用关键词后置判断代替语义成题。
- 原来外部提交仅记录执行，未完成候选保存。现在 MCP 与日常共用同一保存、合并或不转题入口；本批完成装配后，逐项提交会返回下一条来源，全部处理后进入评分，评分完成后完成原榜单。
- 搜索来源、读到的内容与限制随执行保存，并传到评分材料中。材料合并后仍能看到对应的成题材料，不只有来源标题。
- 删除独立热点转机会契约、固定热点角度与生成分支、无调用方的旧候选提示词和解析器、旧多领域直写候选参数及旧热点重提入口。综合热点汇报保持现有规则；音乐不自动转题。
- 旧输入装配不能与新 Skill 混跑，旧弱候选输出不再被当前接口接受。
