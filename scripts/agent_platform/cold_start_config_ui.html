系统范围说明

系统不生成、不制作、不发布视频；用户完成外部发布后，可以从独立入口登记发布事实并进入 P0—P7 观察。

文案和音频交付完成后的处理

音频确认后，内容生产链结束。视频制作和发布由你在系统外完成；发布登记与 P0—P7 反馈通过独立正式入口处理，需要你明确登记和确认，不会自动启动。

外部发布登记

你在外部平台发布后，在这里登记事实。系统会核对自有账号、领域、已确认音频和最终文案是否对应；不会自动发布。

P0—P7 观察记录

每个观察点只记录一次。拿不到数据时也要登记“缺失”和原因，不能用猜测补齐。

P7 复盘与人工确认

系统只整理候选判断，不会自动把一次表现写成长期开关或经验规则；必须由你最后确认。
