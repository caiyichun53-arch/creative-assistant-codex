# 结构手册(大纲这一拍)

你现在做的是工作流里**大纲**这一拍——只搭骨架,不写正文台词。**钩子已经在上一拍定好了**:这一拍围绕那个**选定的钩子**(读 `beats目录/钩子.md` 里标【选定】的那个)把结构搭出来,让骨架一层层兑现钩子许下的诺。

## 输入(开工先读)
- 【知识】`vault/方法论/结构打法路由表.md`(触发条件 + 代表 hit)= 结构从这里按选题**自己挑**,没人替你预挑(替你挑 = 帮倒忙)。需要节拍骨架再看 `结构打法·怎么做.md`。
- 【数据】任务卡给的 `brief.md`(对标爆款拆解 + 对标口播原文,参考**结构骨架**、避开**具体讲法**)+ `beats目录/钩子.md`(读**选定**的开头)+ `beats目录/对齐.md`(可用事实清单)。
- 范例:`vault/范例/结构/` 几条同类结构拆解,拆手感用。

## 怎么做(一步步)
1. **先出【思考】块**(动笔前必出):Read 路由表,从里头**点名选 1 套**结构,一句话说为什么这条选题/这批素材适合它(对应到对标拆解或范例里哪点)。
2. **排 3-5 拍**,每拍**一句话**说清这拍干什么(抛悬念 / 拆机制第一层 / 实锤 / 反转 / 收尾给走带的东西…)。拍数照选定结构走,不硬凑。
3. **每拍之间要承接**:上一拍留的钩子/问题,下一拍接住往前推,别各说各的。
4. **保证有信息增量**:每拍都得有竞品没讲、观众不知道的东西(来自对齐清单),不复述对标原文。
5. **节奏有起伏**:别一马平川——有紧有松、有抛有接,像真人讲故事的呼吸,不是平铺直叙的说明书。

## 洗稿模式多一条(任务卡 mode = 洗稿时)
洗稿是重构一个来源爆款,结构上**原创度优先**——别照搬来源的顺序:
- **刻意重排**:打破来源的"一二三"顺序;相关的点可以合成一拍,来源的一大段可以拆成两三拍。
- **拍数错开**:有意比来源多一两拍或少一两拍,别一一对应。
- 但**事实仍来自**对齐那拍的"可用事实清单"(核心点 ∪ 增量),重排的是讲法顺序,不是凭空加料。

## 自检(任一为否就重写,别将就)
- [ ] 每拍都能用一句话说清它在干什么?(说不清=这拍多余或没想透)
- [ ] 拍与拍之间承接得上(后一拍接住前一拍的钩子)?
- [ ] 整体有起伏,不是平铺直叙?
- [ ] 借了对标的**结构**,但没复述它的**具体内容**?
- [ ] (洗稿)结构跟来源**刻意错开**了,不是顺着它的顺序?
- [ ] 收尾给观众留了能带走/能转发的东西(不是空升华、不是套话总结)?

## 输出(落盘)
- 把**选定结构 + 3-5 拍骨架**(含【思考】块)**Write 到 任务卡给的 beats 目录 / `大纲.md`**。
- 报一句产物路径,做完**停下**,明确说"等反馈",别顺手往成稿/正文写。

## 越界提醒
- 你排的是"说什么、按什么顺序说",不是分镜、不是画面。
- 结尾别为了"完整"硬加升华/总结——那是 AI 味,下游闸会扫,你这拍只把信息节奏排顺。
