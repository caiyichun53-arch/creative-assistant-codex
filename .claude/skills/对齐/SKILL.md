# 对齐手册(第 0 拍:理料 + 定模式)

这一拍**不写文案**,只干两件事:**把能用的事实生料理清并落盘** + **确认这次的创作模式**。做完停下等反馈。

## 输入(开工先读)
- 任务卡给的 **brief.md**(材料包)。
- 任务卡给的 **mode**(洗稿/原创)。
- 洗稿模式:brief 里 **`analyze_source` 的【核心点】**(读这个,别读对标口播原文逐字——见下)。

## 铁律:只交生料,不产洞察
列的是**事实**(硬数字 / 内幕 / 人的代价 / 时间线),不是你的**解读**。
"你以为 X 其实 Y""最反常识的是…""矛头转回观众"——这些角度/立意**一概不许在这拍出**。它是预嚼,会把后面的钩子锚死成套路句式。角度、爆点等钩子那拍从生料里现挖。

## 看任务卡的 mode,走对应那节
任务卡已按选题来源给了建议模式,你这拍把它确认下来。

### A · 洗稿(沿用对标主题)
有一个来源爆款,你是**重构它 + 加增量**,不是从零另起。
1. **原文隔离**:**别去逐字读对标口播原文**(读了就会不自觉抄它的话和句式)。改读 brief 里 `analyze_source` 拆好的 **【核心点】**——那是已经抽象过的事实,安全。
2. 把【核心点】+ 研究包里**搜来的增量**(对标没讲的)合成一张"可用事实清单"。
3. 清单里标一下:哪些是**来源已有**、哪些是**新增量**。

### B · 原创(发现新主题)
没有单一来源,从选题方向 + 研究包另起。
1. 通读研究包,把**竞品都没讲、观众不知道**的事实生料理成清单。
2. 同样只列事实,不列角度。

## 输出(落盘)
- 把"可用事实清单"**Write 到 任务卡给的 beats 目录 / `对齐.md`**(洗稿模式标好 来源已有/新增量)。
- 报一句:产物路径 + 确认的 mode。
- 做完**停下**,明确说"等反馈",别顺手往钩子/大纲写。
