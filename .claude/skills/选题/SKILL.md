# 选题手册(出 · 判 · 选)

这一步干三件事:**出选题**(从料源产候选)→ **判选题**(用判断维度评)→ **选**(收拢排序)。三件事用的是**同一把尺子**——该领域的「选题判断维度」。

## 那把尺子(出和判都靠它)
`vault/方法论/选题判断维度.md`(每领域一份,从该领域爆款 reduce 出来)。**先认准 domain**——领域不同维度不同;没有该领域的维度文件就说明、**别套别的领域**。Read 它,记牢每一维的"怎么看强弱"。
- **判**的时候:它是评分标准。
- **出**的时候:它是靶子——出选题就是**奔着命中这几维去**。
> 尺子是数据产物(reduce),随爆款更新。本手册只给"怎么用尺子"的流程,不抄维度内容(抄了两处漂)。

## 一、出选题(从料源产候选,绝不凭空编)
从下面这些**有真实依据**的料源产选题角度——

- **对标爆款**:看该领域什么题爆过 → **换品类/换角度/换人群复制它的套路**(如"lululemon 成本5毛卖80"这套"成本售价极端反差",可换到别的暴利品类)。
- **评论区**(最值钱):来源爆款评论里观众**反复追问/争论/喊"你该讲讲X"**的 → 直接立题(这是真实需求,不是你猜的)。
- **研究缺口 / 争议**:研究里竞品没讲、观众想知道的角度。
- **当下热点 / 季节**:正在发生的消费、民生、价格异动。

**出的时候就奔着判断维度去**:每个候选都要能说出**它打算命中哪几维**(尤其该领域核心那几维)。一个角度若核心维度都命不中,别出它。出一批(比如 5-8 个粗胚),进下一步筛。

## 二、判选题(逐维评)
拿那几维**逐维过**每个候选:在每一维上强不强、命中哪几维、哪几维挂零。**别给笼统总分,落到具体维度。** 该领域**最核心那几维**(维度文件里排前/「一句话总览」强调的)挂零的,基本不值得做。

## 三、选(收拢排序)
1. **来源信号先验**(候选带来源标签时):`🔥评论延展`(从评论真追问长)> `研究·争议` > `研究·信息缺口`。评论是观众真问的,起评最高。
2. **收拢**:语义去重(同义合并,比意思不比前几个字)/ 砍跟已有选题没差异的 / 砍核心维度挂零的。
   > 差异化在这只当**去重过滤**,不是打分维度;可搜不可搜料**不在这判**(那是选中后从零重搜的可行性)。
3. **排序取 top 3-5**,按 `来源信号 × 维度命中` 综合排。**不够格宁缺毋滥**(少而厚)。
4. **每个配一句"为什么值得做"**:强在哪几维 + 什么来源。
5. **产出排好序的候选 + 理由即止,最终拍板哪一个不在这一步。**

## 场合(同一把尺子,四种用法)
- **给某领域出一批新题**:走 出→判→选 全套。
- **选题流候选筛选**:候选池/推来的一批 → 跳过"出",直接判→选。
- **衍生方向收拢**:`spinoff.py --from-topic N` 爬出的延展方向 → 判→选(`🔥评论延展` 优先)。
- **原创题判断**:自己想的一个题 → 用维度看成不成、哪几维弱、能不能补强。

## 护栏
- **出不凭空编**:选题角度必须有真实依据(爆款/评论/研究/热点),不许瞎想一个题。
- **判/选只认数据**:标准只对照「选题判断维度」(提炼自爆款),不手写规则、不眼比库、不拿通用直觉。维度从爆款长、随领域变——躲"维度爆炸 + 拍脑袋"两个坑。
- **认准领域**:取对应 domain 的维度文件。
- **只出/判/选,不入库不写**:真正建选题入库是脚本(`daily_topics` 机械造 / `new_topic` 原创 / `spinoff --pick` 衍生),写文案是创作流程——都不在本手册。
