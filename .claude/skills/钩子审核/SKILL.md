# 钩子审核手册(钩子拍闸 · 逐个判候选开头)

**这是什么**:作者在"钩子"这一拍交出 3 个候选开头 + 推荐后,成稿**之前**的一道独立闸。趁还没动笔写正文就把钩子的硬伤挑出来——钩子定了,后面整篇都顺它写,钩子坏了等成稿才发现就白写一轮。
**谁来判**:独立判卷方(你)。作者自己挑不出自己钩子的毛病(自己写的护短),必须独立的人拿这把尺子量——和篇级审稿、humanizer 一个道理。
**绝不丢给终选品味方**:干净的候选才交上去做终选。
**别越界**:句级 AI 味(破折号/三段式/否定排比…)归 humanizer,**这里一概不碰**。这里只判"这句作为钩子立不立得住、有没有失真"。

## 怎么用
- 对作者交的**每个候选开头逐个判** PASS / WARN / FAIL;另对"整组 3 个"判最后一条。
- **FAIL 必须引那一句原文 + 一句话说清问题**。
- **任一 ⭐关键项 FAIL = 这个开头作废**。若**推荐的那个**或**全部 3 个**都作废 → 打回钩子拍、带上打回意见重产;改完重判。
- 还剩干净候选 → 把**干净的开头 + 你的审核注记**一起交回终选。**别把带硬伤的钩子直接放行。**

---

## 每个候选开头逐条判
1. ⭐ **不剧透结论** —— 检验:这句把视频的核心答案/结论说破了 = FAIL(剧透了就不叫钩子)。
2. ⭐ **数字/事实对得上素材** —— 检验:开头的每个数字、每句断言,都能在材料包/研究包里查到,且**没放大、没张冠李戴**(把"A 是 B 的 3 倍"说成"冰过没冰整体差 3 倍"就是张冠李戴)= FAIL。
2b. ⭐ **数字之间的关系不能似是而非** —— 检验:开头并置多个数字时(倍数/对比/占比),它们的**指代和换算必须一念就对、不会被听众误读成算错**。每个数字各自对素材**还不够**,凑一起的关系也得说清。例:"全世界一年杀 590 万头……得养 1 亿头……是现在的两倍"——"两倍"其实指"现存总量约 5000 万",却紧贴着 590 万,听着像在说 1 亿 = 590 万 × 2,自爆成算错 = FAIL。判法:把开头当成只用耳朵听一遍,若任一倍数/对比的指代会落到错的数上 = FAIL。
3. ⭐ **没为冲击失真/过头** —— 检验:为博眼球把话说得比素材支持的更绝对(例:瓜本身是甜的,却说"没一个是真的甜")= FAIL。挑衅可以,失真不行。
4. ⭐ **脱离标题能独立听懂** —— 检验:这句得靠标题/封面补全才看得懂 = FAIL(观众只听这一句)。
5. ⭐ **只有说出来的话** —— 检验:混进画面/镜头/分镜/字幕/BGM 指示 = FAIL(口播标注 `/` 和语气括号不算)。
6. **前 5 秒有抓手** —— 检验:数字/反差/反常识/悬念/痛点,至少占一个;平淡开场(没任何抓手)= WARN。
7. **留悬念、不过早解释** —— 检验:第一二句就把"为什么"的机制/原因解释了(不是剧透结论,是过早交底)= WARN。
8. **没卸力词** —— 检验:"不一定/可能/其实也/大概/或许/哦"等把力道自己泄掉的词 = WARN(出现 ≥2 个 = FAIL)。
9. **不是旁观者视角** —— 检验:主语是"消费者/大家/市面上"在讲别人的事,而不是"你"= WARN(防御本能没被触发)。
9b. ⭐ **代入别硬预设观众情况** —— 检验:开头**断言**一件对很多观众为假的事("你家长辈花大几千买了阿胶""你肯定也这么干过"),那批"其实没有"的人立刻"不是我"、当场划走 = FAIL。要"你"代入(第 9 条)、但别**硬替观众做主**:安全代入 = 近乎人人都有的体验,或用设问("你有没有…")不用断言。挑衅可以,硬预设不行。
10. **能直接念出来** —— 检验:是口语台词,不是书面语长句 = WARN。
10b. ⭐ **藏住了核心、没把料倒在开头** —— 钩子的活是**勾人,不是讲料**。检验:把最猛的数字/内幕/结论一次性摊光、还顺手解释了"为什么",开头读完观众已经"知道得差不多了、没什么想问的"= FAIL(缺口被自己填平,人就划走)。判法:**听完这句,观众心里还剩不剩一个"那到底…?"的钩——一个都不剩 = FAIL。** 这条专盯"猛料堆砌、缺口归零",和第1条(剧透结论)、第7条(过早解释机制)是同一类病的不同面。
> ⚠️ 实测教训(2026-06-23):**别再用"句式像不像范例/像不像'你以为X其实Y'"当判据**——那是打错靶,句式从来不是病,藏不藏、勾不勾才是。盯留存,不盯句式。

## 对整组 3 个判
11. **三个开头分属不同角度/不同招** —— 检验:对照作者【思考】里的切入角度和用的留存策略,3 个是不是塌成同一招的变体(比如全是堆数字)= WARN(打回让作者换不同角度重写,要的是真·多类型供终选)。

## 输出格式
```
钩子审核:开头1 PASS / 开头2 WARN / 开头3 FAIL
逐个:
【开头1】"西瓜每一百克的糖只有苹果的一半…"
  全过 → PASS
【开头3】"同一个西瓜冰过没冰甜度能差三倍…"
  2 ⭐ FAIL —— "差三倍"素材里是"吡喃型甜度是呋喃型3倍",不是整体差3倍 / 数字张冠李戴
整组:11 WARN —— 3 个都在堆数字、都把答案倒在开头,没一个真留缺口
打回意见(给作者):
- 开头3 重产:别把分子层的3倍说成整体差3倍,要么改用真数字,要么换个角度
- 至少 1 个要真"藏住"——把核心答案留作钩,别开头就摊光(10b);3 个走不同切入角度(11)
给终选:开头1、开头2(附注记)
```
> 钩子过了再进成稿。成稿后另走篇级审稿(`审稿` skill)。
