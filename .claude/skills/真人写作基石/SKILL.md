# 真人写作基石节点(人类范文 → 通用写作基石)

逆向引擎里从**人类范文**提炼通用真人写作痕迹的生成节点。**不在交互会话里触发**——由 `extract.py` 把范文确定性分块(作者轮转交错)后,`map` 逐块提炼,`reduce` 多级归并成一份基石 + 领域/风格观察。

铁律:**正向范例,不要规则训诫**;每条痕迹**摘原文例句为证**;矛盾保留张力不强行统一。

## 提示词模板 · map

<!-- prompt:map -->
```text
下面是 {n} 篇**人类写的**文章。提炼这些人"到底是怎么写的"——真人写作痕迹,要正向范例不要规则训诫。

只看真人本来就有的写法特征,各维度给**原文引用为证**(必须摘原句),具体到可模仿:
- 节奏/句长:长短句怎么错落、在哪断句、哪里留白
- 用词:口语 vs 书面的切换、动词/量词的温度、有没有"不完美"的真诚处
- 句式:陈述还是设问、转折怎么接、有没有跳步/省略
- 情绪:把情绪铺表面还是藏下一段、怎么克制
- 结构:开头怎么进、信息密度、怎么收尾(讲完就停 vs 讲圆)
- 任何让你觉得"这一定是人写的、AI 写不出"的细节

输出 markdown,按维度分节,每条特征后跟摘自原文的例句。不写空话、不写"AI不该怎样"。

最后另起一节 `## 本批风格观察`:本批横跨多位作者(看文件名的作者目录)。点出各作者区别于他人的写法、谁更口语化、哪些可迁移到短视频口播;若发现某条痕迹是多位作者共有的,标一句"跨作者共性"。简短即可——供归并时产出"领域/风格层"观察与共性线索。

# 文章合集
{articles}
```

## 提示词模板 · reduce

<!-- prompt:reduce -->
```text
下面是若干份"真人写作痕迹"提炼笔记(来自对人类范文的分块分析)。把它们归并成一份去重、分维度、保留最有代表性原句例证的真人写作范例。

要求:同类痕迹合并、矛盾保留张力不强行统一、每个维度留最锋利的几条带原句的例子;正向范例,不写规则禁令。输出 markdown,分维度。

输出分两部分:
1. `# 真人写作范例(通用)`:跨作者的共性痕迹,分维度+原句例子。
2. `# 领域/风格观察`:汇总各块的「本批风格观察」,按作者/风格归类,标出哪些口语化、可迁移到短视频泛科普——这部分喂"领域规律"层,不是通用基石。

# 各块笔记
{notes}
```
