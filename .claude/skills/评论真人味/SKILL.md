# 评论真人味节点(评论语感 → 基石)

逆向引擎里把**评论区真人语感**归并成一份 always-on 基石的生成节点。**不在交互会话里触发**——由 `comment_voice.py` 抽各视频评论的"说话方式"层喂进来。`map` 归一批,料多装不下时 `reduce` 多级归并。

铁律:只归**怎么说话**(语气/口语词/句式节奏/玩梗/打比方/情绪流露),**不归**聊什么话题/痛点(那是选题材料);每条共性必须**跟真实评论原句为证**(一字不改、不自己编)。

## 提示词模板 · map

<!-- prompt:map -->
```text
你面前是同一领域【{domain}】里 {n} 条爆款视频【评论区】提炼出的"观众真人说话"片段——只保留了"大家是怎么开口说话的"这一层(口语 / 语气 / 玩梗 / 打比方 / 网络表达),每条带真实评论原句为证。

请把它们归并成一份**评论真人味基石**:跨视频提炼"真人在评论区到底是怎么说话的"共性语感——**正向范例,不是规则禁令**。这份基石会全量交给口播文案写手当语感地基,让它写出来的话像真人随口说,而不是书面腔 / AI 腔。

# 死规矩
- 只归纳**怎么说话**(语气、口语词、句式节奏、玩梗方式、打比方的习惯、情绪怎么流露);**不要**归纳"大家在聊什么话题/什么痛点"——那是选题材料,不进这份基石。
- 每条共性后面**必须跟真实评论原句为证**(从下面清单里摘,一字不改,别自己编);原句是这份基石的命根子。
- **少而厚**:只留几条最稳、最普遍、最有代表性的,别凑数,别写"要接地气""有网感"这种空话。
- 维度名用**大白话**短词,别用文绉绉的长修饰句当标题。
- 这是给写口播的人找手感用的:抓那种"一听就是活人随口说的"质感——包括不完整、跳脱、带情绪、自带立场的地方,不是教人写规整漂亮的句子。

# 输入(各视频评论区 · 只含"说话方式"层)
{digest}

# 输出格式(markdown,不要前言,不要解释你做了什么)
## 评论区真人语感 · 速记(先记这几条)
(3-6 条跨视频最普遍的"真人怎么说话"共性,每条:一句话点破 + 紧跟一句真实评论原句)

## 分维度(每条特征后跟摘自评论的真原句)
### (大白话维度名,如:语气/态度)
- (特征一句话) —— "真原句"
### (大白话维度名,如:口语词与句式)
...
(维度从料里长出来、不必凑满;只要立得住的)
```

## 提示词模板 · reduce

<!-- prompt:reduce -->
```text
下面是若干份"评论区真人语感"的初步归纳(各自来自一批爆款评论)。把它们再归并成一份去重、分维度、保留最有代表性真原句的**评论真人味基石**。

要求:同类语感合并、每个维度留最有代表性的几条带真原句的;只留"怎么说话",删掉混进来的"聊什么话题/痛点";正向范例,不写规则禁令;大白话维度名。输出 markdown,格式同各份笔记(速记 + 分维度)。

# 各份笔记
{notes}
```
