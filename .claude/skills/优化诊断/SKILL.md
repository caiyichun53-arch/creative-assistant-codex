# 优化诊断手册(整篇优化意见 · 只挑不改)

篇级审稿是"地板线(崩没崩)";这一步是"提一档(够不够好)"。**判在你、改在作者**——你只独立通读、点出能更好的地方并落盘成意见,**绝不自己动笔改稿**(改是精修拍的活;你下场改会把文风磨平)。

## 怎么用
1. **对照 `精修` skill 的优化维度逐项过整篇**(8 条维度在 `精修` 手册里,**本手册不抄**——抄了改一处漏一处、两处会漂)。逐项扫:删冗余 / 虚变实 / 提密度 / 调节奏 / 顺说服链 / 钩身咬合 / 加口气 / 收尾的劲。
2. **点到具体段落**:哪段冗余、哪段弱、哪里节奏垮、哪里说服跳步——**引原文那一句 + 一句话说怎么提**。笼统说"可以更好"没用,要落到具体位置和改法。
3. **只挑"能更好",不重复审稿的硬伤**(剧透/AI尾巴/水段/篇幅那些篇级审稿管过了),**也不碰句级 AI 味**(破折号/三段式那是 humanizer 的)。
4. **落盘**:把这份意见 Write 到 `beats目录/优化意见.md`(精修拍的数据输入)。

## 护栏
- **只产意见,不改稿**:你不重写整篇——那会把文风磨平。一条意见 = 引原文 + 怎么提,交给作者去落实。
- **可以判"无需优化"**:初稿本来就好、挑不出有价值的优化点,就如实写"无需优化",别为优化而优化、别硬挑。
- **守边界**:硬伤归审稿、句级 AI 味归 humanizer,你只在这两摊之间那一层——"把合格稿提一档"。

## 输出格式
```
优化意见(对照 精修 维度):
1. 删冗余 —— 原文"其实可以说在某种程度上…" / 三个虚词叠着,删到"…",更狠
2. 虚变实 —— 原文"很多人都这么干" / 换成研究包里的具体数字"X 成的人…"
3. 调节奏 —— 第3拍连着4个长句铺下来,砸不下来 / 末尾补一个短句重锤
...
(挑不出 → 写:无需优化,初稿已到位)
```
> 意见落实是作者翻 `精修` 手册改;改完另走句级 humanizer。
