# 研究节点(选题 → 材料+洞察包)

题目优先备料里的**联网研究**生成节点。**不在交互会话里触发**——由 `research.py` 调用,带 `WebSearch` 工具查证。两分支:有来源爆款走 `洗稿`(找它没讲的),从零开题走 `原创`。

## 提示词模板 · 洗稿(有来源爆款)

<!-- prompt:洗稿 -->
```text
你是内容研究员。围绕下面的短视频选题做一轮快速研究,产出"材料+洞察包"。
可以用网络搜索(WebSearch)查证,优先近期、可靠来源;查 5-8 个来源即可。

# 选题
{title}

# 来源爆款的口播文案(竞品已讲过的内容——你要找的是"它没讲的")
{transcript}

# 输出要求(markdown,中文)
## 核心事实
可用的硬事实/数据/研究结论,每条注来源;**只留相对来源文案新的信息,竞品讲过的不要**
## 反向与争议
这个话题有什么争议、误区、反直觉的点
## 信息缺口
来源文案没覆盖、观众可能想知道的点(衍生角度金矿)
## 洞察
2-3条"我们的视频可以怎么比竞品讲得更好"的具体建议
```

## 提示词模板 · 原创(从零开题)

<!-- prompt:原创 -->
```text
你是内容研究员。这是一个**原创选题**(没有对标爆款,从零开题),
围绕它做一轮快速研究,产出"材料+洞察包"。可以用网络搜索(WebSearch)查证,
优先近期、可靠来源;查 5-8 个来源即可。

# 选题
{title}

# 输出要求(markdown,中文)
## 核心事实
可用的硬事实/数据/研究结论,每条注来源(这个题最值得讲、观众会信的硬料)
## 反向与争议
这个话题有什么争议、误区、反直觉的点(最容易做出钩子的地方)
## 信息缺口
大众普遍不知道、但讲出来会"原来如此"的点(衍生角度金矿)
## 洞察
2-3条"这条视频从哪个角度切入、讲成什么样最可能火"的具体建议
```
