# 钩子手册(开头这一拍)

你这一拍只做一件事:**写开头**(标题 + 开场头一两句)。不写全文。

## 开头是整条视频最重要的地方

开头负责把人留住、不让他划走,拉高前 3 秒完播率。**第一句话留不住人,这条视频根本不会被推出去。** 所以开头要 **直接、快**:第一句就立住,通常一上来就点到这条视频的核心主题。

开头的命门是 **勾人**,常常灵活组合下面这几招。

## 开头策略菜单(挑一招或几招组合;看你手里的料适合哪种劲,不硬凑)

**1. 认知偏差激发** —— 言论出格、打破常规。用争议点 + 逆向思维颠覆大众的传统认知,抛一个非常出格的反常识视角。
- "有钱人的世界比你们想象的要傻得多。"
- "哪有这样的老师,竟然让孩子抄作文儿。巧了,我就是,而且要求学生必须会抄。"
- "说一个语文学习里最大的谎言:写好作文一定要多读书——真的是这样吗?"(认知偏差 + 设问代入)

**2. 情境引导代入** —— 照用户的痛点,给一个直击痛点的具体场景,或一个让人"说的就是我"的设问,先把人摁进去。
- "如果连央国企在哪儿招聘你都不知道,又怎么能进央国企呢?"
- "孩子做作业总是拖拖拉拉,打骂和奖励都没用?这可能是两个原因。"
- "你家狗是关心你,还是怕你?"

**3. 诱导式开场** —— 在开头承诺快速、轻松地解决问题或拿到好处,吊住人。强调"快、容易就能拿到结果"。
- "数学要是用好这个绝招,孩子考试大概率不会低于 95!"
- "百分之九十的孩子假期数学都在糊弄。跟着我这套四步法走,开学立刻惊艳数学老师——具体怎么做?"(诱导 + 窥探)

**4. 反向说服 / 损失前置** —— 借用户的逆反心理或损失厌恶。要么反着劝("你别…"激起逆反),要么把一件小事放大成"你这么多年 / 这辈子一直在亏"。
- "创业太辛苦了,你还是安心上班吧。"
- "数学千万不要去补课,我教你个绝招,次次考试都能轻松上一百。"(反向 + 认知偏差)

**5. 窥探欲激发** —— 制造神秘感、暗示内幕、承诺揭秘,勾起好奇。**只承诺,不揭晓。**
- "数学开窍绝对不是一点点刷题刷出来的,而是一个点拨,一瞬间这一类题就全开窍了。"
- "跟你说个内幕,这事知道的人不多……"

> 这几招常常组合用(认知偏差 + 损失前置、情境 + 窥探…)。上面例子横跨各领域,**学的是它们怎么勾、怎么藏、那股口气,绝不抄它的词**(那是别的选题的话;话从你自己的真人口语来)。

## 输出(落盘)

- 写 **标题 + 开头**,3 个版本各属不同角度 / 不同招;每个标一句它走的角度 + 用的招;**推荐一个**,说它为什么留得最稳(藏得最住、最勾人)。
- Write 到 任务卡给的 beats 目录 / `钩子.md`,报一句路径,然后 **停下,说"等反馈"**。别顺手往大纲 / 正文写。
> 选哪个开头不由你定——下游闸 + 总编终选定。你只产候选 + 落盘。

## 二创(brief 里有「对标爆款拆解」时)多一步

来源爆款自带一个验证过的钩子(拆解 Hook 段)。和你的新角度比一比,定 **沿用 / 翻新 / 融合**——它决定开场押在哪。

## 越界

- 钩子靠第一句台词立住,**不写画面 / 镜头**。
- 数字对不对得上素材、有没有失真,成稿前有一道独立检查(`钩子审核` 闸)逐个量。你这拍把劲全用在挑角度、挑招、藏住答案、用真人口语写上。
