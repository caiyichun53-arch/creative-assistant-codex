# 归纳节点(多篇 DNA → 领域层范例 + 路由表 + 判断维度)

这是逆向引擎里 **reduce(找共性)** 的生成节点。**不在交互会话里触发**——由 `reduce.py` 把某领域已拆的多条 DNA 抽成 digest,逐维填模板调 LLM,产物只进**领域层**(`vault/方法论/`、`vault/范例/`)。

两块用途:
- **路由表**:某一维(钩子/结构/选题…)的多条要点 → 可复用打法路由表 + 范例卡。
- **判断维度**:从「选题/张力/共鸣」三段料 → 一把"判一个新选题值不值得做"的尺子(`选题判断维度.md`,每领域一份)。

## 提示词模板 · 路由表

<!-- prompt:路由表 -->
```text
你是短视频爆款方法论分析师。下面是同一领域【{domain}】里 {n} 条已验证爆款的「{dim}」要点清单(每条标了 hit 编号和相对基线超额倍数=验证强度)。

请归纳它们在 **{focus}** 上的**共性打法**,产出两部分。

# 输入清单
{digest}

# 任务
1. 归纳出 3-6 类**可复用的打法**(不是流水账,是能套用到新选题的招式)。
2. 每类打法挑 2-3 个**最强、最典型**的样例(优先超额倍数高的;同质的只留一个最好的,别凑数)。
3. 每个样例写成一张范例:要具体、可直接模仿,引用原文,不写"要有冲击力"这种空话。

# 输出格式(严格遵守,我要按它切分;不要加多余前言)
先输出方法论路由表(一个 markdown 表格):

## 路由表
| 打法 | 什么时候用(触发条件) | 标签 | 代表 hit |
|---|---|---|---|
| (打法名) | (面对什么样的选题/素材时选它) | (从词表选:{tags}) | (hit编号,逗号分隔) |

然后逐个样例,每张范例用下面这块,块之间用 `===范例===` 隔开:
===范例===
hit_id: (编号,必须是清单里出现过的)
打法: (属于上面哪类打法)
标签: (从词表选,逗号分隔:{tags})
点题: (一句话,这个范例教会什么)
本体: (拿来模仿的正向内容——{body_hint};直接引用原文,可多句)
为什么有效: (一两句,指向可模仿的机制)
```

## 提示词模板 · 判断维度

<!-- prompt:判断维度 -->
```text
你是短视频爆款选题分析师。下面是同一领域【{domain}】里 {n} 条已验证爆款的选题相关拆解(选题角度 / 张力冲突 / 共鸣转发;每条标了 hit 编号和相对基线超额倍数=验证强度)。

请归纳:这个领域的选题之所以"好"(能爆),**反复踩中了哪几个判断维度**。这套维度是一把尺子——用来判断"一个新选题/衍生方向值不值得做"。

# 死规矩
- 维度要**从下面这些爆款里长出来**,不是套通用模板;**不同领域维度本就不同**,只归纳这个领域真实呈现的,别硬塞放之四海的空泛维度。
- **3-6 个维度,少而准**,别凑数、别写"要有冲击力"这种空话。
- 每个维度要**可操作**:能拿它去看一个新方向在这维度上强不强。
- **维度名要大白话、一目了然**:2-4 字的口语短名(像"跟我有关 / 反常识 / 有人坑你 / 数字够炸 / 想转给谁"这种,让人一眼懂),**绝不用"反常识反转的'一句话荒诞感'"这种文绉绉的修饰长句当名字**;复杂的解释全放进"什么意思"那行。

# 输入清单
{digest}

# 输出格式(markdown,严格遵守,不要前言)
## 选题判断维度({domain})
### 维度1:(维度名)
- 什么意思:(一句话,这维度判的是什么)
- 怎么看强弱:(拿到一个新选题,从哪几个可观察的点看它在这维度上够不够强)
- 代表:hit X(它怎么踩中这维度)、hit Y(...)
### 维度2:...
(3-6 个,每个同上结构)

## 一句话总览
(这个领域的好选题,核心反复在赌的是什么)
```
