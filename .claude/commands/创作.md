# 创作 · 选题 $ARGUMENTS(你=信使,不是写手)

你(主会话)在这条指令里是**信使/编排**,**绝不自己写文案**——写文案是「写手」子agent 的活,它在独立会话里写(避免主会话的工程默认腔污染文风)。你只做四件机械活:备料 → 填工单 → 派活并逐段转达过审 → 登记。

## 一、备料(你自己读,先不打扰用户)
1. 材料包 `data/topics/$ARGUMENTS/brief.md`(选题/对标爆款拆解/对标口播原文/研究包/目标篇幅)。**读不到就停下**,告诉用户该选题还没备料(需先选中并跑 prepare_topic),不要硬编。
2. 账号人设 `vault/人设/张芝士.md`(账号、领域、目标篇幅范围)。
3. **匹配方法论(按规则,别拍脑袋)**:按 brief 选题的题材/标签,在 `vault/方法论/结构打法路由表.md`、`钩子打法路由表.md` 里对"触发条件/标签"匹配,各取 2-3 个候选打法(连同代表 hit 编号)。
4. **取范例(按规则,少量)**:按选题标签 × 强度,从 `vault/范例/结构/`、`钩子/`、`文风/` 各取最相关的 1-2 张(桶空就跳过;**绝不全量、绝不编造**)。

> 备料的匹配/取范例现在你按上面规则手动做;以后会落成确定性脚本(机械匹配,不靠你拍脑袋)。

## 二、填工单
读模板 `templates/写手_dispatch.md`,把所有 {{占位}} 替换成上面备到的真实值:
账号 / 选题id / 领域 / 人设路径 / brief路径 / 结构打法候选 / 钩子打法候选 / 范例 / 目标篇幅(+上下限) / 草稿路径=`data/topics/$ARGUMENTS/draft_v1.md`。
填好的**整段文本**就是派活 prompt。

## 三、派活 + 逐段过审(往返)
1. 用 **Agent 工具**拉起写手:`subagent_type: "写手"`,`prompt:` = 填好的工单。**记住它返回的 agent ID**(后续往返要用)。
2. 写手按它自己的工作流一拍一拍来(对齐→大纲→钩子→成稿),**每拍停下**。它每产出一拍,你**原样转达给用户**(连同它的【思考】块),等用户拍板。
3. 用户给反馈后,用 **SendMessage**(to: 那个 agent ID)把反馈回传给写手,让它续下一拍。**始终发给同一个 ID**——重新用 Agent 工具 = 换了个新写手、丢掉全部上下文。
4. 如此往返直到成稿。期间用户随时插嘴改方向,你就把话传给写手。

## 四、审稿(篇级闸 · 你跑 · 绝不丢给用户)
写手成稿(已 Write 到 `data/topics/$ARGUMENTS/draft_v1.md`)后,你**对照 `templates/审稿清单.md` 逐条机械判**这版稿(13 条,引原文判 PASS/WARN/FAIL)。你不是写手、是独立判卷,这道闸合规。
- **任一 ⭐ 关键项 FAIL → 不放行**:把"打回意见"(引原文 + 具体改法,对应清单条目)用 **SendMessage**(发给三步里那个写手 agent ID)传回写手 → 写手改 → 你**重判**。循环到 ⭐ 全过。
- 全 ⭐ 过、WARN 可接受 → 篇级通过,进润色。**别自己动手改稿**——改是写手的活,你只判 + 转达意见。

## 五、润色(句级闸 · humanizer-zh)
篇级过了,用 **Skill 工具调用 `humanizer-zh`**,对 `draft_v1.md` 跑句级去 AI 味(24 模式 + 5维1-10 评分,<35 返工)。
- humanizer **只动句级**(破折号/此外/三段式/否定排比…);**别让它碰结构/钩子**——那是篇级、已审过,动了就越界。
- 它带 before→after 改写;改完仍落回 `draft_v1.md`(这就是最终"AI 稿"版本)。

## 六、登记 + 交付
- 跑 `python scripts/content/save_draft.py $ARGUMENTS --author ai --version 1` 登记这版 AI 稿。**务必带 `--version 1`**:写手成稿固定在 `draft_v1.md`,而 save_draft 不指定版本会取最高版号——topic 里若残留旧 `draft_v2.md` 就会登记错文件。
- 给用户:**最终稿全文 + 审稿结果(哪些条过/打回过几轮)+ humanizer 句级改动摘要 + 评分**。
- 用户接着改成自己的版本 → 走阶段5 `diff_draft.py` 抽对照范例(不在本指令内)。

## 边界(信使纪律)
- **你不创作、不替写手落笔、不自己改稿文笔**;选哪个打法、怎么写都是写手的判断。
- 你**能做且只做**这几样机械活:备料读文件、填工单、派活转达、**跑审稿清单(篇级判卷)**、**调 humanizer skill(句级闸)**、跑 save_draft 登记。
- 门**串行**:审稿(篇级)先 → 写手改 → humanizer(句级)后。结构崩的稿别先润色,省一轮。
- 禁词 regex 校验(阶段5,校验器待建)以后并进审稿/润色之间;现在没有就跳过。
