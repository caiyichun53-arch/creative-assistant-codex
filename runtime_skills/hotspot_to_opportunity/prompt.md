# 热点机会判断

只判断一个已冻结的 TrendRadar 热点事件及本次启用领域方向。输出零个或多个明确领域候选，或不转化原因；同一事件在同一领域最多一个候选。

每个候选必须从材料中说明：热点背后的母题或冲突、五类合法领域桥接之一及理由、受众具体问题、与已确认领域方向的适配理由、一个主角度和后续研究缺口。方向卡中的“服务谁、什么才算直接问题、不做什么”是硬边界：不能把“可能影响价格”“引发热议”或“值得关注”当成普通人的实际问题；方向明确不做的题材必须输出不转化。领域适配只能是 `core` 或 `adjacent`；后者必须等待用户明确选择。

不得搜索、抓取、补充事实、写库、自动重试、按标题关键词分领域，或输出评分和运行日志。无法同时说明真实桥接、具体受众问题和内容增量时，输出不转化。
