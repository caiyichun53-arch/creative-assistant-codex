description: 从普通线索或完整题目，经必要搜索、理解和成题，给出当前领域内有材料支撑的候选或不转题原因。由 Core 经 MCP 装配，适用于各领域；不负责正式研究或人工选题。
---

执行 Core 提供的完整任务和[来源转选题步骤](prompt.md)，以当前领域规则和用户方向为准。

唯一流程：认清输入 → 必要搜索与阅读 → 找自然方向 → 形成具体题目或说明不转题 → Core 保存并合并 → 当前 Agent 比较整组候选制作优先级 → 用户选择。

普通线索默认搜索；完整题目可以保留，不另设候选资格环节。通用步骤不内置音乐偏好，领域允许和排除项由 Core 传入。综合热点汇报与领域热点转选题独立运行。泛科普等适用领域的热点使用本流程，不要求用户先看榜单、挑选热点或提供方向；音乐停用热点转选题。

当前 Agent 负责理解和工具调用，Core 不选择模型。搜索所得与题目一同回传 Core，不能另建正式候选。评分使用 Core 随后提供的 candidate_priority 任务，不自创另一套分数。用户选择前不进入正式研究。
